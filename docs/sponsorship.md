# Supporting Permesh

Permesh is a local, read-only access inspection tool. Voluntary sponsorship can
fund maintenance, provider qualification against real APIs, platform support,
documentation, and security work. It does not purchase a different set of access
findings or a certification of complete visibility.

The core and official connectors remain MIT-licensed. There are no paid feature
gates. Sponsorship does not change the license of existing releases;
third-party dependency licenses and notices still apply.

A company can propose funding a publicly available connector or its ongoing
maintenance. A useful proposal identifies the system and API version, the review
question it would answer, the smallest required observation scope, an authorized
test tenant, and who can validate the results. Agree on the public deliverable,
maintenance responsibility and qualification criteria before work starts. Funding
does not make an unqualified integration production-ready or grant a sponsor
access to another user's data.

Consultancy, training and contractual support are separate services with
separately agreed terms. This document offers no prices, response-time promises,
service commitments, or guaranteed delivery dates.

No verified sponsorship destination is configured in this repository yet. This
page intentionally has no payment link or sponsorship badge. Maintainers must
verify the destination before adding one.

For a small evaluation with optional, manually shared feedback, see the
[pilot guide](pilot-guide.md) and [feedback template](pilot-feedback.md).
