# Permesh 0.1.0-alpha.1

First public CLI prerelease for evaluation. This is not the stable v0.1 release.

## Available

- Offline demo, strict workspace configuration, deterministic identity resolution, and access paths.
- `doctor`, `user`, `admins`, `orphaned`, JSON output, and shell completions.
- Explicit provider installation and update checks from the GitHub catalog, digest-bound trust, guided setup, workspace approval, and named env/keychain credentials.
- External GitHub provider 0.1.0, released separately; Google directory source and demo remain bundled.
- Read-only provider access, local processing, no backend, telemetry or persistent access database.

Use the [installation guide](../installation.md), then `permesh init --demo`.
For GitHub, follow [getting started](../getting-started.md#connect-github).
Downloading a provider does not grant execution trust. Existing legacy GitHub workspaces require [explicit migration](../github-migration.md).

## Evaluation limits

- Binaries are unsigned and unnotarized. Checksums detect corruption; they are not signatures. No build attestation, SBOM or reproducible-build guarantee is provided.
- Tested targets are macOS Apple Silicon/Intel, Linux GNU x86_64/ARM64 and Windows x86_64. Runner success does not establish support for older OS versions. Linux binaries use system libraries from Ubuntu 24.04; no musl/static portability claim is made.
- CI exercises synthetic Windows Credential Manager and Linux Secret Service round trips, including unavailable-service redaction. Dedicated interactive desktop acceptance remains open. Use environment references if native storage is unavailable. macOS Keychain has passed a synthetic credential round trip on an earlier development revision.
- GitHub has passed read-only health and access parity checks. Dedicated live tests of team inheritance, pagination, denied permissions and real token revocation remain open; mock API coverage is not equivalent to these exercises.
- Google uses externally supplied short-lived OAuth access tokens. Live Google tenant qualification and built-in refresh/browser login are pending.
- Results show observed access with explicit completeness and certainty, not exhaustive effective authorization. External programs are trusted native code, not sandboxed.
- The provider protocol remains draft; compatibility changes before 1.0 will be documented. Workspace schema, output schema and protocol versions remain separate contracts.
- No crates.io, Homebrew, Scoop, WinGet or AUR publication. The CLI has no self-update command; replace the executable to upgrade. Provider update commands are separate.

Private vulnerability reports: [GitHub security reporting](https://github.com/NIPE-Solutions/permesh/security/advisories/new).

The release page records the exact revision, qualification run URLs, target archives and checksums. [Stable qualification gates](../releasing.md) remain open where noted above.
