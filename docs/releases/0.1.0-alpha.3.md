# Permesh 0.1.0-alpha.3 candidate

Unpublished prerelease candidate for access-review evaluation. No alpha.3 release
or new provider catalog entry is available. Published alpha.1 and alpha.2 bytes
remain unchanged. Qualification results must bind the exact merged revision and
original artifacts before promotion; historical alpha.2-version trial archives
are not alpha.3 release assets.

## Changes since alpha.2

- Explicit stable-account identity mappings and pinned JSON identity inventories.
- Private versioned snapshots, offline inspection and scope-aware diffs.
- Read-only offboarding assessment, advisory plans and JSON/HTML verification.
- Resource queries, focused local policies and offline provider development tools.
- Scoped native-provider approvals, launch integrity checks, negotiated discovery,
  explicit network context and portable target-specific executable pins.
- Host-owned exact-field credentials from 1Password Connect and separately
  dispatched Vault/OpenBao KV v2; explicitly selected temporary AWS profiles.
- Seven separate provider 0.2.0 candidates: GitHub, Google Workspace, Cloudflare,
  AWS IAM, GitLab, Entra and AWS Identity Center. They are not bundled or published
  by this CLI release preparation.

## Compatibility and migration

Access JSON uses [schema 2](../migrations/domain-schema-2.md); control commands
retain schema 1. Local snapshot, diff and offboarding artifacts have independent
versioned contracts. Consumers must check the command, schema, completeness and
limitations. No SDK or negotiated protocol stability is declared.

Legacy bundled provider execution is removed. Follow the explicit
[GitHub](../github-migration.md) and [Google](../google-migration.md) migration
instructions. GitHub 0.1.0 remains the published provider; new negotiated-v1
providers need separately qualified 0.2.0 packages. Unpublished packages require
reviewed local artifacts, explicit trust and workspace approval. Downloading or
updating a package does not authorize execution, adopt workspace pins or deliver
credentials. A minimum compatible published host for provider 0.2.0 has not yet
been established by packaged acceptance.

## Qualification and promotion

The [implementation report](../audits/architecture-hardening-backlog.md#access-review-delivery-evidence-and-remaining-gates)
retains completed source and historical trial evidence. Alpha.3 requires its own
five-target native run, exact version checks, all 20 archive/inventory/checksum
subjects, same-run signed provenance and original attestation bundle, independent
verification, and packaged install/trust/setup/approval/query acceptance. Record
source SHA, run, hashes and results here as those checks complete.

Publication requires explicit authorization and the [release gates](../releasing.md).
Promote original qualified bytes without rebuilding or recompression; verify
staged downloads before publication and public attestation lookup afterwards.
Never mark this alpha as latest stable. Provider releases and catalog changes
follow their separate qualification and publication process.

## Evaluation limits

Only the previously recorded limited NIPE-Solutions GitHub read-only exercise has
live evidence. It does not qualify alpha.3 packaged bytes. Broader GitHub checks,
Google, Cloudflare, AWS, GitLab and Entra tenants and separately authorized
Connect/Vault/OpenBao services remain prerequisites. Synthetic API fixtures do
not establish real API permissions or complete effective authorization.

Interactive desktop credential stores and Windows terminals require separate
acceptance. Apple/Windows platform signing and notarization are absent. GitHub
provenance authenticates build subjects, not platform reputation, live-provider
correctness or reproducible builds. The dependency inventory is not a standards
SBOM. MIT remains the project license; required dependency notices ship separately.

No remote remediation, backend, telemetry, hidden update, automatic credential
refresh or infrastructure mutation is introduced. Future phases 6–7 remain
roadmap/ADR work. No verified sponsorship destination is available.
